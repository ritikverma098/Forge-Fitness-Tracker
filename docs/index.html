YOUR PHONE. YOUR RECORDS.

Keep your focus.
Keep your data local.

Forge stores your training and nutrition records on your device. There are no accounts, ads, analytics or automatic cloud sync.

Useful without a connection

Workout logging, your diary and installed food catalogs work offline. The bundled catalog sets itself up locally when you first open Nutrition.

You choose the downloads

Internet access is used for release checks and optional update or food-pack downloads. App installation always requires Android’s approval.

Back up what matters

Create and restore portable backups through Android’s file picker. Keep a checked copy outside the app before reinstalling or changing devices.

START WITH ONE SESSION

Your first few minutes.

  1. 01

    Install Forge

    Download the official APK below. Open it and approve Android’s installation prompt. Android 8.0 or newer is required.

  2. 02

    Log a workout

    Choose Start Workout, give it a name and add an exercise. Enter weight and reps, mark a set Done, then finish to save it to History.

  3. 03

    Make it your routine

    Save a routine for next time. In Nutrition, let the local food library finish setting up, then add a food to your diary and set your goals.

  4. 04

    Keep a backup

    In Settings → Backup & restore, create a backup somewhere you control. Review History and Progress as you add more sessions.

Upgrading from 1.4.1 or another development-signed build?

Version 1.4.3 uses the production certificate introduced in 1.4.2. Moving from a development-signed build requires a one-time verified backup → manual uninstall → install → restore. Uninstalling removes app data. Save and check your backup outside Forge before uninstalling. Optional food packs may need to be downloaded or imported again.

Follow the complete migration guide ↗
How do I check the download and install it?

Compare the official APK’s SHA-256 with SHA256SUMS.txt. Open the APK using your browser or file manager. If Android asks, allow installation from that source, then approve installation.

Already using production-signed Forge 1.4.2? Use Settings → About Forge → Check for Updates to update in place. Download & Install verifies the APK, then Android asks you to approve installation.

HELP SHAPE WHAT COMES NEXT

what gets in your way.

Forge is in active development. A clear bug report or a small suggestion can help improve the next release.

Report a bug or suggest an idea ↗

GitHub requires an account to submit an issue. Include the Forge version, Android version, steps and what you expected. Redact screenshots and logs; keep personal backups, diary exports and signing files private.

How do I get updates?

Use Settings → About Forge → Check for Updates. Forge can download compatible official updates inside the app; Android asks you to approve installation. Development-signed builds require the one-time migration above.

Can I use it offline?

Yes. Training, nutrition and installed food catalogs work offline. Internet is needed for update checks and optional downloads. The app does not automatically sync your records to a cloud account.

What about my backups?

Android automatic backup and device transfer are unsupported. Use Forge’s portable backup in Settings. Backups contain personal records; keep them private and verify them before uninstalling.

Where can I inspect the source?

The source is public on GitHub. The repository has no published overall source-code license. See the repository’s third-party notices for dependency and data licenses.
